## A WGSL toolkit? What does it have?

Everything below runs in your browser on the [playground](/playground/), compiled to
WebAssembly from the same source as the CLI and the editor extension.

<CardGrid stagger>
	<Card title="A minifier" icon="pencil">
		A customizable state of the art WGSL minifier.
		[Toggle its options live](/playground/) and watch the byte and gzip counts move.
	</Card>
	<Card title="A validator" icon="document">
		No need for a WebGPU context. Check and validate your shader code at light speed anywhere (terminal, editor, web, etc...).
		[Break a shader](/playground/) and the diagnostic arrives as you type.
	</Card>
	<Card title="Discoverability" icon="setting">
		A WGSL reflection tool for your code. Powerful insights on WGSL at the reach of a function call.
		[See the bindings, entry points and memory layouts](/playground/) it pulls out of a shader.
	</Card>
	<Card title="A terminal tool" icon="add-document">
		Build your shader code pipeline with the WGSLender CLI tool that performs actions while you keep working.
	</Card>
	<Card title="LSP" icon="open-book">
		Hook it all in your favourite editor (vscode, helix, codemirror, etc) with the WGSLender LSP.
		[The playground editor](/playground/) is CodeMirror talking to it over WebAssembly.
	</Card>
</CardGrid>
