# Plan 03 — C example: harden + fully test the existing `examples/c/` suite

**Reality check first:** unlike JS/TS and Rust, the C example **already exists** — ten
zero-argument programs under `examples/c/` (`minify.c`, `validate.c`, `reflect.c`,
`minify_and_reflect.c`, `lint.c`, `lint_fix.c`, `rename.c`, `compile.c`,
`change_type_apply_by_id.c`, `remove_declaration_apply_by_id.c`) plus a 16-line
`Makefile`. They build and run correctly today. What is **missing** is everything this
plan adds: automated tests (currently **zero** — verified exhaustively), Linux
portability (two examples use BSD-only `strnstr`), a richer minify subexample
(JSON-options path), and doc fixes.

**Status:** ready to execute. Verified against `main @ 017cb1d`, 2026-08-05, macOS arm64,
zig 0.16.0, Apple clang 21. On that date: `zig build lib && make -C examples/c` built all
ten, and `./minify`, `./validate`, `./reflect` produced correct output.

## Verified current state (do not re-derive)

- Build: `zig build lib` → `zig-out/lib/libwgslender.a` + `zig-out/include/wgslender.h`
  (`build.zig:69-83`). The examples Makefile compiles each file as
  `cc -Wall -Wextra -std=c11 -I../../include -o <name> <name>.c ../../zig-out/lib/libwgslender.a`
  (targets: `all`, `clean` only). Built binaries are gitignored.
- The C ABI is stateless/thread-safe; every returned buffer is freed with the **sized**
  `wgslender_free_c(ptr, len)`; `wgslender_version_c` returns a static pointer (never
  freed). Version `1.1.0`.
- The three core examples this plan treats as the canonical subexamples:
  - `minify.c` (43 lines): prints `wgslender <version>`, `Original (<n> bytes):` + the
    shader, `Minified (<n> bytes):` + output. Uses only the **bitflag** path
    (`wgslender_minify_c(..., WGSLENDER_OPT_DEFAULT)`); exits 1 on `.error`.
  - `validate.c` (44 lines): three sections — `--- valid shader ---`,
    `--- undeclared identifier ---`, `--- strict mode ---` — each printing
    `valid: true|false, errors: N, warnings: N` then `diagnostics: <json>`. Always exit 0.
  - `reflect.c` (34 lines): prints `Reflection JSON:` + the v2 envelope
    (`{"version":2,"bindings":[…],…}`) for a uniform-struct + storage-array compute
    shader; exits 1 on `.error`.
- **No automated testing exists**: `build.zig` never references `examples/`; no Makefile
  `test` target; no script in `scripts/`; no CI anywhere in the repo (and per repo
  convention, none is wanted — tests stay local/on-demand).
- **Portability bug:** `change_type_apply_by_id.c:20` and
  `remove_declaration_apply_by_id.c:22` call `strnstr()` — BSD/macOS-only, not in
  glibc/POSIX; these two files fail to build on Linux.
- **Known C-surface asymmetry (document, don't change):** `wgslender_minify_c` *and*
  `wgslender_minify_json_c` return **plain minified text** — the JSON envelope with
  `errors[]`/sizes/sourceMap that the WASM/npm path returns exists only behind
  `wgslender_minify_and_reflect_c`. Options JSON uses the `wgslender.json` camelCase
  keys (`minifyWhitespace`, `keepNames`, …); malformed options JSON silently degrades
  to defaults (`src/lib.zig:274-290`).
- **Stale docs found:** `README.md:69-74` claims `zig build -Doptimize=ReleaseSafe`
  produces the static library — wrong, only `zig build lib` does. `rename.c:11`'s
  header comment uses a `-L… -lwgslender` link form inconsistent with every other
  example. `docs/C-API.md` documents only a subset of the 22 exports / 7 result structs.

## Ground rules

- TDD reds-first: each block first creates the check that fails (a missing `make`
  target, a portability lint that trips on real bugs, a runner expectation the current
  code doesn't print), confirms the exact red, then goes green.
- The test harness is **table-driven**: one `expect <binary> <substring>…` line per
  example; adding coverage = adding a line.
- No CI. Entry point is `make -C examples/c test` (plus `make lint-portability`).
- One conventional commit per block. Don't commit unrelated working-tree changes.
- Before pinning any expected substring, run the actual binary once and copy from real
  output (oracle-pin) — the tables below are the starting point, not gospel.

## Block 1 — Test harness (red: `make test` target doesn't exist)

**Context recap:** `examples/c/Makefile` has only `all` and `clean`. All ten binaries
build via `make -C examples/c` after `zig build lib`, take no arguments, and print
deterministic-shaped output to stdout (exact byte counts may drift with the minifier —

1. **Red.** Run `make -C examples/c test` → expected:
   `make: *** No rule to make target 'test'. Stop.` Confirm.
2. Write `examples/c/run_tests.sh` (POSIX sh, executable):
   ```sh
   #!/bin/sh
   # Table-driven smoke tests for the C examples. Run via `make test`.
   set -u
   cd "$(dirname "$0")"
   [ -f ../../zig-out/lib/libwgslender.a ] || { echo "libwgslender.a missing — run: zig build lib" >&2; exit 2; }
   pass=0 fail=0

   expect() { # expect <binary> <required-substring>...
     bin=$1; shift
     out=$("./$bin" 2>&1); status=$?
     if [ "$status" -ne 0 ]; then echo "FAIL $bin: exit $status"; fail=$((fail+1)); return; fi
     for want in "$@"; do
       case "$out" in *"$want"*) ;; *) echo "FAIL $bin: output missing '$want'"; fail=$((fail+1)); return ;; esac
     done
     echo "ok   $bin"; pass=$((pass+1))
   }

   expect minify                          "wgslender " "Original (" "Minified (" "@compute"
   expect validate                        "--- valid shader ---" "valid: true" "valid: false" "--- strict mode ---" "\"diagnostics\""
   expect reflect                         "\"version\":2" "\"bindings\"" "\"entryPoints\"" "\"structs\""
   expect minify_and_reflect              "\"minify\"" "\"reflect\""
   expect lint                            "lint:" "diagnostics:"
   expect lint_fix                        "fixed source"
   expect rename                          "rename_apply JSON" "\"edits\""
   expect compile                         "magic: 00 61 73 6d"
   expect change_type_apply_by_id         "stable id: v1:"
   expect remove_declaration_apply_by_id  "stable id: v1:"

   echo "---"; echo "$pass passed, $fail failed"
   [ "$fail" -eq 0 ]
   ```
   Then **oracle-pin**: `make -C examples/c && cd examples/c && ./lint`, `./rename`,
   `./compile`, … once each, and adjust any substring above that doesn't match the
   real output verbatim (the `minify`/`validate`/`reflect` rows were verified on
   2026-08-05; the other seven come from code reading and need one confirmation run).
   Note the deliberate negative-space checks: `validate` must show **both**
   `valid: true` and `valid: false` — a validator that stops rejecting bad shaders
   fails the row.
3. Add to `examples/c/Makefile`:
   ```make

   	./run_tests.sh

   .PHONY: all clean test
   ```
   (extend the existing `.PHONY` line rather than duplicating it).
4. **Green.** `zig build lib && make -C examples/c test` → `10 passed, 0 failed`,
   exit 0. Also verify the failure path honestly: temporarily break one expectation,

## Block 2 — Portability: kill `strnstr`, add a Linux compile lint (red: lint trips)

**Context recap:** `change_type_apply_by_id.c:20` and
`remove_declaration_apply_by_id.c:22` use BSD-only `strnstr()` inside their local
`extract_id()` helpers, so they don't build on glibc. Zig doubles as a
cross-C-compiler, which gives us a *local* Linux build check with no CI and no Docker:
`zig cc -target x86_64-linux-gnu` compiles against glibc headers.

1. **Red.** Add to `examples/c/Makefile`:
   ```make
   # Compile-only check against glibc headers — catches BSD-isms (e.g. strnstr) locally.
   lint-portability:
   	for f in *.c; do \
   	  zig cc -std=c11 -Wall -Wextra -Werror=implicit-function-declaration \
   	    -target x86_64-linux-gnu -I../../include -c -o /dev/null $$f || exit 1; \
   	done
   ```
   (add `lint-portability` to `.PHONY`). Run `make -C examples/c lint-portability` →
   **expected red:** implicit-declaration error on `strnstr` in exactly the two files.
   Confirm both file names appear before fixing anything.
2. **Green.** In both files, replace the `strnstr` call with a small local helper
   (bounded, no libc extension):
   ```c
   /* Bounded substring search; strnstr is BSD-only. */
   static const char *find_sub(const char *hay, size_t hay_len, const char *needle) {
       size_t n = strlen(needle);
       if (n == 0 || hay_len < n) return NULL;
       for (size_t i = 0; i + n <= hay_len; i++)
           if (memcmp(hay + i, needle, n) == 0) return hay + i;
       return NULL;
   }
   ```
   Keep each file's surrounding `extract_id()` logic byte-for-byte otherwise.
3. Verify: `make -C examples/c lint-portability` clean, **and** `make -C examples/c test`
   still `10 passed` (behavior-neutral change — the runner proves it).
4. Also fix the `rename.c:11` comment to use the same positional-archive link form as
   every other example (`cc examples/c/rename.c -Iinclude zig-out/lib/libwgslender.a -o …`).
5. Commit: `fix(examples): portable substring search in C examples + linux compile lint`

## Block 3 — Deepen the minify subexample: JSON-options path (red: new runner row)

**Context recap:** `minify.c` only shows the frozen bitflag path
(`wgslender_minify_c(src, len, WGSLENDER_OPT_DEFAULT)`). The modern, extensible path is
`wgslender_minify_json_c(src, len, opts_json, opts_len)` — same plain-text return, but
options arrive as `wgslender.json`-style camelCase JSON (`keepNames`, `sortDeclarations`,
…), which is the **only** way to reach post-freeze options. The demo shader in
`minify.c` contains a helper function whose name disappears under default
identifier-renaming — perfect for a `keepNames` demonstration. (If the current shader
has no such helper, add one small `fn` first.)

1. **Red.** Extend the `minify` row in `run_tests.sh` **first**:
   ```sh
   expect minify "wgslender " "Original (" "Minified (" "@compute" "With keepNames (" "helper_name_here"
   ```
   (use the real helper name). `make -C examples/c test` → the `minify` row fails on
   the two new substrings. Confirm.
2. **Green.** Extend `minify.c` with a second section after the existing output:
   build a literal options string like
   `{"keepNames":["<helper>"]}`, call `wgslender_minify_json_c`, print
   `With keepNames (<n> bytes):` + the code, free the buffer (sized free). Add a short
   comment block stating the two C-surface facts a reader must know:
   (a) both minify entry points return **plain text** — no JSON envelope, no size
   counters, no error list (compute sizes yourself; the full envelope exists only via
   `wgslender_minify_and_reflect_c`); (b) malformed options JSON silently falls back
   to defaults, so keep the options literal valid.
3. `make -C examples/c test` → `10 passed`. `make lint-portability` still clean.
4. Commit: `feat(examples): demonstrate the JSON-options minify path with keepNames`
